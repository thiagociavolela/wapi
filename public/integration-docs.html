API da Central

Envie templates, agende mensagens e acompanhe a entrega pelo seu sistema.

Baixar OpenAPI JSON

1. Autenticação

Use a chave configurada em INTEGRATION_API_KEY no servidor. Clique em Authorize e informe somente a chave. As requisições usam Authorization: Bearer SUA_CHAVE.

2. Evite envios duplicados

Na criação, envie um Idempotency-Key único por evento, com 8 a 190 caracteres. Reutilize a mesma chave apenas para repetir a mesma solicitação.

3. Acompanhe o envio

202 confirma o registro na fila. Consulte o ID retornado para verificar processamento e entrega. Os testes de POST e DELETE executam ações reais neste ambiente.
